# AI Banking Copilot

An interactive banking payments operations dashboard built with Python, Streamlit, and Ollama.

## Features

- Payment transaction dashboard with sample data
- Filters for payment status and payment rail
- Payment exception analysis
- AI-assisted investigation of failed and pending payments
- Payment volume charts and downloadable CSV reports
- Status-based handling for completed transactions

## Technology Stack

- Python
- Streamlit
- pandas
- Ollama with Llama 3.2
- Git and GitHub

## Current Scope

This is a learning and portfolio prototype using fictional payment data. It is not connected to a live banking or Temenos system.

## Future Enhancements

- Upload payment data from CSV
- Improve payment reconciliation and exception classification
- Add automated test cases and evaluation metrics
- Improve audit logging and investigation traceability
